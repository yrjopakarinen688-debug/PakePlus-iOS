# 校园请假移动端原型

这是一个可直接打开的移动端/PWA 原型，按参考截图实现了学生请假与外出申请主流程：

- 基本信息、联系方式、请假类型、原因和起止时间
- 自动计算请假时长
- 证明材料图片上传与预览
- 手写签名画布，支持上传签名图片、清除重写
- 提交后生成申请编号，展示详情、审批流程和数据日志
- 使用浏览器 `localStorage` 保存演示数据，刷新页面仍可查看最近一条申请
- 提交按钮会提示具体缺少的必填项；联系方式、紧急联系人、请假原因和签名需要先完成
- 起止时间使用浏览器时间值自动计算时长，材料上传后会立即显示预览，签名支持触摸和鼠标绘制
- 已接入申请人和辅导员头像资源，详情流程和日志中会使用对应头像
- 申请人姓名现在可直接填写，默认值为“王悦坤”，详情、流程和日志会同步使用填写的姓名
- 流程采用“发起申请 → 辅导员角色 → 具体老师”的递层结构；老师头像、真实姓名、手机号和黑色手写风格签名会按每份申请生成

直接打开 `index.html` 即可体验。项目现在包含 PWA 清单、应用图标和离线缓存：把整个文件夹部署到 HTTPS 静态网站后，安卓 Chrome 选择“添加到主屏幕”，iPhone Safari 选择“添加到主屏幕”，即可像 App 一样启动。当前版本是前端演示，尚未连接学校账号、后端数据库或真实审批系统。

如果要发布 Android APK 或 iOS 安装包，可以在这个 PWA 基础上使用 Capacitor 打包；网页表单、头像、随机老师和本地保存逻辑可以直接复用。
